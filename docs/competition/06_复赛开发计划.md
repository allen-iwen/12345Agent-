## 二、架构映射：本地五节点 → 极智平台

| 本地节点/能力 | 极智平台实现方式 | 备注 |
|---|---|---|
| 录音输入 | 工作流「文件/语音输入」起始节点 | 平台**语音转文字节点暂不可用** |
| 讯飞 v2 + SenseVoice 双引擎转写 | **平台内**：大模型节点选 `qwen3.5-omni-plus` 做语音转写（官方指定替代路径）<br>**增强**：HTTP 节点调用本地服务 `/api/asr` 作为高精度兜底 | 双路径，平台内链路必须能独立跑通 |
| 领域词典纠错 + LLM 降噪 | 代码块节点（词典替换表内置）+ 大模型节点（降噪提示词） | 词典数据文件随画布导入 |
| ① 诉求理解（要素提取） | 大模型节点（`deepseek-v4-pro` / `qwen-plus-latest`）+ 结构化输出 | 提示词直接复用本地版本 |
| ② 标准化工单生成 | 大模型节点 + 结构化输出 | |
| ③ 事项分类（12 类+辨析） | 大模型节点 + **知识库检索**（12 类目录含定义/典型/辨析） | 复用 v1.1 目录，LOO 100% 的那份知识 |
| ④ 承办单位推荐 | 大模型节点 + 知识库（部门职责规则）+ 条件分支（职责交叉 → 提示人工判断） | 复用部门职责规则库 |
| ⑤ 答复草拟（政策引用） | 大模型节点 + 知识库（政策 RAG：`text-embedding-v4` + `gte-rerank-v2` 重排） | 8 部法规全文导入平台知识库 |
| 人工审核门（interrupt） | 平台**对话流/工作流人工确认节点** + 输出结构化结果供查看修改 | 平台内的"人在环"实现方式以用户指引为准 |
| 白盒轨迹 | 平台「运行日志逐节点回放」+ 外接工作台轨迹抽屉 | 平台日志作为主证据，截图入 PPT |
| 未诉先办预警 / 减负账本 | 代码块节点（聚合逻辑）+ 输出提示 | 加分项，保留 |
| 完整审核工作台（Web） | **外接系统**：本地 FastAPI+React 部署到公网服务器，平台 HTTP 节点建单后回传链接 | 提升"完整性与使用体验"15% |

**平台能力我们重点用**：条件分支（信息不足/职责交叉）、知识库+重排器（分类与政策检索）、代码块（词典纠错、预警聚合）、HTTP 节点（外接服务）、运行日志回放（白盒证据）。

| 6 | 预回复/回访话术 | 答复节点 + 政策 RAG，输出预回复+回访脚本+政策依据 | 引用真实政策名（QC 校验过） |
