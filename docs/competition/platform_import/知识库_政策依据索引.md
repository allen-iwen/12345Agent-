# 知识库导入 · 政策依据索引

> 用途：平台知识库「政策依据」检索源；答复引用须来自本清单（防虚构法条）。
> 说明：法规全文已随仓库提供（backend/data/policies/library/），可整篇上传平台知识库。

## 精选法规清单
- **《国务院办公厅关于进一步优化地方政务服务便民热线的指导意见》（国办发〔2020〕53号）**
  - 适用范围：12345 热线运行总体规范：受理范围、转派办理、回访考核机制
  - 使用说明：涉及热线受理流程、办理时限、回访机制的答复可引用
- **《中华人民共和国噪声污染防治法》（2022年6月5日施行）**
  - 适用范围：社会生活噪声、建筑施工噪声、工业噪声的监督管理与法律责任
  - 使用说明：噪声扰民类诉求的办理依据；夜间（22时至次日6时）建筑施工噪声由生态环境/城管部门监管
- **《物业管理条例》（国务院令第504号修订）**
  - 适用范围：物业服务、物业费、小区公共设施、业主大会与业主委员会
  - 使用说明：物业服务质量、收费争议、小区公共区域维护类诉求
- **《城市市容和环境卫生管理条例》（国务院令第101号）**
  - 适用范围：占道经营、户外广告、垃圾清运、市容市貌管理
  - 使用说明：占道经营、乱堆乱放、环境卫生类诉求
- **《中华人民共和国消费者权益保护法》**
  - 适用范围：商品和服务质量、价格公示、退换货、消费纠纷处理
  - 使用说明：消费维权、明码标价、预付卡类诉求
- **《保障农民工工资支付条例》（国务院令第724号）**
  - 适用范围：拖欠农民工工资的清偿责任、工资专用账户、维权渠道
  - 使用说明：欠薪类诉求；工程建设领域欠薪由行业主管部门与人社部门协同处理
- **《医疗保障基金使用监督管理条例》（国务院令第735号）**
  - 适用范围：医保基金使用、定点医药机构管理、骗保处理
  - 使用说明：医保报销、定点药店/医疗机构违规类诉求
- **《中华人民共和国道路交通安全法》**
  - 适用范围：道路通行、违法停车、交通事故处理、公交优先通行
  - 使用说明：交通秩序、车辆占道、公交站点被占类诉求
